# Naerio UI 규칙 (2026-11-15)

기준: `insane-design/pleos/design.md`(Pleos 토큰) 위에 아래 앱 규칙을 덮어쓴다. 검토 도구: ui-ux-pro-max(앱 UI 체크리스트), kill-ai-slop(35개 패턴).

## 글보다 그림
- 화면 문장은 제목 1줄과 꼭 필요한 값만 둔다. 설명은 첫 실행 온보딩(4장)과 정보(i) 버튼으로 옮긴다.
- 경로는 도식으로 보여 준다: 실선은 차, 점선은 도보. 하차점은 검은 원, 주차 진입구는 파랑 사각 P, 방문 건물은 건물 아이콘.
- 확인 항목은 아이콘 + 모서리 상태 표식 + 한 단어 캡션(FactIcon). 같은 캡션은 가장 나쁜 상태 하나로 합친다.

## 상태 표시
- 확인됨: 채운 체크 원(본문색). 확인 필요: 물음표 원(보조색). 안 됨: X 원(빨강 `#FA293C`, 아이콘에만).
- 배경 틴트 칩, 같은 색 3단계 상태 상자, 아이콘을 틴트 원에 넣는 방식은 쓰지 않는다.

## 구조
- 한 영역에 표면 하나. 목록은 카드 안 카드 대신 구분선.
- 간격은 관계로: 묶음 안 8 to 16dp, 묶음 사이 32 to 40dp.
- 안쪽 반경 = 바깥 반경 - 여백 (세그먼트 20 - 6 = 14).
- 아이콘은 Material Rounded 한 계열, 크기 토큰 28/36/48/64dp.
- 터치 76dp 이상. 아이콘만 있는 버튼에는 설명(contentDescription)을 단다.
- 단계 표시는 4칸 막대(순서가 실제로 있는 흐름이므로 유지).
